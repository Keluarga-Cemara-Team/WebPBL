📋 Standar 40 Kolom Dataset

File Excel Anda dapat menyertakan seluruh 40 kolom atau sebagian besar kolom penting di bawah ini:

  • Identitas: Person_ID, Full_Name, Age, Gender, Country
  • Pekerjaan: Occupation, Education_Level, Employment_Status, Monthly_Income_USD, Work_Hours_Per_Week, Remote_Work
  • Kesejahteraan: Job_Satisfaction, Work_Life_Balance, Sleep_Hours, Sleep_Quality
  • Kesehatan Mental: Stress_Level, Anxiety_Score, Depression_Score, Mood_Score, Emotional_Stability
  • Gaya Hidup: Physical_Activity_Hours, Exercise_Frequency, Meditation_Minutes, Screen_Time_Hours, Coffee_Cups_Per_Day, Smoking
  • Hasil ML: Burnout_Score, Burnout_Risk, Mental_Health_Status, AI_Wellness_Recommendation
✅ Fleksibel: Huruf besar/kecil & nama alias Indonesia otomatis dikenali sistem.
⚡ Alur Proses Import
  1. File Excel/CSV dibaca dan divalidasi oleh Python & Pandas.
  2. Kolom otomatis dipetakan ke Domain Entity (Clean Architecture).
  3. Jika ada nilai risiko burnout yang belum terisi, model ML menghitungnya otomatis.
  4. Setiap responden disimpan ke database aktif (Cloud Firestore / SQLite).
  5. Halaman tabel diperbarui secara instan.
